# Gestor de Gastos Personales 💰

API REST desarrollada con **NestJS**, **Prisma ORM** y **PostgreSQL** para la gestión de gastos personales y categorías de clasificación, con reglas de negocio para la protección de categorías por defecto del sistema.

---

## 📋 Requisitos Previos

Asegúrate de tener instalado en tu equipo:

* **Node.js** (v18.x o superior)
* **npm** (incluido con Node.js)
* **PostgreSQL** (servicio de base de datos en ejecución)
